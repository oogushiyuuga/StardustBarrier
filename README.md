# 星屑結界 — HOSHIKUZU

ドット絵の和風弾幕シューティングゲームです。ブラウザで動作します。

## 遊び方

`dist/index.html` をブラウザで開くか、このディレクトリで次を実行して `http://localhost:8000` にアクセスしてください。

```sh
python3 -m http.server 8000 --directory dist
```

「ゲームスタート」または Enter キーで開始します。

| 操作 | キー |
| --- | --- |
| 移動 | 矢印キー / WASD |
| ショット（長押しで連射） | Z / Space |
| 低速移動・当たり判定の表示 | Shift |
| ボム | X |
| 一時停止・再開 | Esc / P |

スマートフォンでは画面のドラッグで移動し、自動でショットします。ボムと低速移動は画面下のボタンで操作できます。

## 内容

- 星降る竹林ステージとボス「月影ノ蝶」
- EASY / NORMAL / HARD の3段階の難易度
- 弾をかすめて得点する GRAZE、ボム、ハイスコア保存
- 水色と白の自機、赤紫とオレンジの敵、ピンクと金色の敵弾
- サウンド切り替えとレスポンシブ画面

HTML・CSS・JavaScript と Canvas で実装しています。ビルドや追加パッケージのインストールは不要です。表示用フォントは Google Fonts から取得します。
